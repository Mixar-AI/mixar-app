# Self-Update (`modules/common/updates/`)

One **Restart & Update** click stages the release installer, spawns a detached helper, quits, and relaunches; the downloads page is the fallback. Decisions live in `core/install_flow.py` (`plan_restart`, `apply_and_restart`) so they are testable under the `bpy` mock; config is `mixar.json` → `updates.{channel,check_delay_seconds,auto_download,downloads_url}`. Install paths carry no version (pinned by `tests/test_update_packaging_paths.py`). Windows staging lives in `%ProgramData%\Mixar\Updates` (a per-machine MSI runs elevated and must read the installer from a shared location); the installer is trusted only after the backend `sha256` matches AND its signature matches the running app's (`core/verify.py`, which also returns the signer's certificate thumbprint); the detached helper never lives in the install directory; a quit that does not happen is recovered by a 15s watchdog that returns state to READY. On Windows only the MSI-registered copy self-installs (`app_paths.classify_windows_install`; others get the browser). Before quitting, `core/install_gate.py` checks who runs from the install dir through a native Win32 process table (`core/win_processes.py`: Toolhelp snapshot + image path + creation time + visible windows, no subprocess, PID-reuse-safe parent links): abandoned Mixar-connector pythons are ended, other Mixar windows / live connectors / other programs get the "Close other apps to update" toast, and Mixar's own background work (our descendants, windowless `mixar.exe -b`) gets a "Finishing background work" toast plus a 2 s timer that continues the update once clear (Cancel; bounded by `BACKGROUND_WAIT_MAX_S`). Helper v3 waits for the install dir as a safety net, runs every tool by its System32 path with delayed expansion off, pins the re-verify to the verified signer thumbprint, keeps the previous MSI log as `msi-install.prev.log`, records registry version/location and relaunches from `InstallLocation`; `purge_stale` never deletes the logs (it trims `update.log` past 1 MB). The next launch classifies the result (`installer.classify_result`, `core/result_report.py`: success / pending_reboot / no_effect / failed + `failure_reason`) — contracts in `docs/modules/self-update.md`.
